# mms-tts-swh (ONNX, int8)

A browser build of [facebook/mms-tts-swh](https://huggingface.co/facebook/mms-tts-swh),
Meta's Massively Multilingual Speech text-to-speech model for Swahili, made
for Ongea with `native/ongea-models/export_mms.py` in the olkeri.space
repository. The sampling noise is fixed in the graph; weights are int8.
